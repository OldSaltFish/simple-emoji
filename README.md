# MyPage

个人网站，汇集各种想做的功能。技术栈选用 SvelteKit，部署在 Netlify。

偏向开源开放的项目会单独建仓库，使用 Vue / React 等热门框架，方便社区参与。例如：

- [VSCode 插件下载](https://vsc-extension.dreamsoul.cn/)

## 技术栈

- **框架**: SvelteKit (SSR)
- **样式**: UnoCSS
- **部署**: Netlify
- **包管理**: Bun
